# Known limitations and demonstration boundaries

Updated 2026-11-14. The connected telemetry/document vertical slice is working. **Full multimodal customer acceptance is not complete.**

1. **Vision model access is blocked.** The existing configured Cosmos checkpoint is absent; the original project recorded model access denial. This upgrade did not search for credentials, attempt a new model download or swap an unverified model. The actual endpoint check returns unavailable. No visual sequence inference, detection boxes or pixel accuracy result is fabricated. The original full-source golden acceptance gate remains unpassed.
2. **Footage is synthetic.** The new clip is original browser assembly geometry and clearly labeled authored footage. Labels and contact motion are manual annotations. It demonstrates workflow presentation, not factory vision accuracy. The original l3_s40 clips remain development placeholders. Before a customer use that implies real camera capability, replace them with approved filmed mock footage and perform correct, incorrect and occluded pixel evaluations using FOOTAGE_GUIDE.md. The synthetic clip can be presented only with its explicit limitation.
3. **The physical presenter laptop is not accessible to this build.** Desktop viewport screenshots and actual headless browser measurements are available. They do not certify 30 FPS on that laptop. Reduced motion, bounded draw loop, adaptive pixel ratio, a bright projector option and a tested 2D fallback are implemented. Onsite laptop/projector rehearsal remains required.
4. **Cause is suspected.** Tool angle records, maintenance notes and correlation support review. They do not establish clamp force, actual preload, personnel fault or which mechanism caused a particular defect. The second model audit and typed constraints improve wording and identity but are not a proof of semantic support. Some model summaries can still oversimplify lot/tool relationships. Inspect the actual cited rows and alternatives before speaking a finding as fact.
5. **The containment boundary is provisional.** The 539-unit demonstrated tool window begins at recorded return, while the last verified good reference check before return is unknown. A Quality reviewer may need broader scope. All 539 have unverified physical joint condition; eight have recorded out-of-limit angles. There are 536 shipped records and three held records projected to finished goods, with no WIP units in this scope. Existing status is synthetic, not a live location feed.
6. **Supplier scenario has a bounded scope limitation.** The broad lot exceeds the UI row budget. Its displayed complete group contains 16 exception units across four lines. Broader lot genealogy stays explicitly unresolved. No truncated sample is mislabeled as a population.
7. **Demo holds are isolated.** Named approval changes only session JSON state. Shipped units enter simulated review; there is no actual shipment hold, recall, MES write, PLC command or robot control. Reset affects that session only. D4 remains suspected and D5 through D8 remain pending without real validation or implementation. No report export certifies a correction.
8. **The workload is bounded.** Two investigations run concurrently and up to 24 active submissions are accepted. The 20-request test is a queue workload, not 20 simultaneous decodes or a production plant scale claim. Model context caps are configured limits, not measurements of full-context multiuser capability. Queue delay and model/tool latency are separate.
9. **Privacy verification has a tested scope.** Browser external destinations and isolated workflow external sockets were denied in controlled tests while authorized local and remote host access stayed intact. Model APIs are loopback and containers network-none. These are not a full security audit or proof about all host traffic. Tailscale clients receive evidence remotely. No NIC byte counter is presented as privacy proof.
10. **Guided sessions use browser capabilities.** Each visitor automatically controls only its own synthetic session. Wall/mobile views receive no control credential. Global operator controls still require the separate local credential. There is no enterprise identity, multi-tenant isolation or public deployment. The existing LAN/tailnet exposure was reused without firewall changes.
11. **Hardware and integration claims are limited.** The Why HP view describes observed local models, memory and workflow timing. No comparative GPU superiority, untested scale out, Z Runtime, OpenShift, FOX, Omniverse or headset integration is asserted. Browser rendering occurs on the viewer device, not a Fury graphics stream.
12. **Publication approval remains pending.** Prior HP IP Marketing Review has not been completed by this task. The owner has explicitly requested a private GitHub release and email delivery. Synthetic application assets may be delivered through that private handoff; gated vision weights, credentials, machine state and model checkpoints are excluded. This does not assert HP review approval.

Working readiness is visible at `/health`. It intentionally distinguishes usable presentation and telemetry/document inference from unavailable vision and full multimodal acceptance. `start_all.sh` checks the working installed slice and excludes the known blocked vision role. `healthcheck.sh --full` retains the separate full multimodal gate. Live startup fails for a missing required role. The recorded installation needs no model or Docker and is labelled throughout.

13. **Handoff validation has a hardware boundary.** A clean Linux ARM64 install and browser workflow are exercised in an isolated folder on this Fury, including a folder path with spaces. This is not a physical second-Fury or partner laptop certification. The live image targets SM 10.3 and the documented memory floor. Other hardware needs its own model fit and driver/container validation. Runtime failures, driver differences and browser/device variability cannot be ruled out by these tests.
14. **Token economics is scoped.** The displayed generation usage excludes embedding/reranking and counts repeated context on each call. Editable USD rates are illustrative assumptions, not market quotes. Local hardware, electricity and operations are not zero-cost and are excluded. No cost saving, model-quality equivalence or total ownership-cost superiority is asserted.
