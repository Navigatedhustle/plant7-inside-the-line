# Plant 7 v1.1.0 private handoff

Start with [the fresh-Fury PDF](docs/Plant7-Fresh-Fury-Guide.pdf) or its [copyable command guide](docs/FRESH_FURY.md).

Use the named application and ARM64 Python-wheel archives in the GitHub release. The application archive contains synthetic fixtures and compiled browser assets. The wheel archive is a separate large download. The live installer downloads the four pinned model checkpoints and serving image from their original sources. Neither live weights nor credentials are mirrored here.

Validation: 49 behavioral tests, live local/Tailscale journey, four desktop sizes, offline Python installation, repeated/concurrent launch, recovery and explicit recording. Hardware/OS provisioning on a physical second Fury remains to be checked there. Vision is unavailable.

Private delivery was explicitly requested by the owner. Existing HP IP Marketing Review is not asserted complete, and no public/open-source licence grant is made. Retain upstream notices.
